# 旅の準備

季節ごとに持ち物を管理できる、静かな旅行準備チェックリストです。
HTML・CSS・JavaScript だけでできています。サーバーもデータベースもログインも不要です。

## 中身

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（画面・機能・デザインすべて） |
| `manifest.json` | ホーム画面に追加したときの名前・色・アイコンの設定 |
| `sw.js` | オフラインでも開けるようにする仕組み |
| `icons/` | ホーム画面用のアイコン画像 |

## 公開のしかた

1. GitHub でリポジトリを作り、上のファイルをすべてアップロードする
2. Settings → Pages → Branch を `main` / `(root)` にして Save
3. 数分後に表示される `https://ユーザー名.github.io/リポジトリ名/` を開く

## iPhone のホーム画面に追加

Safari で開く → 共有ボタン → 「ホーム画面に追加」

## データについて

チェック内容はサーバーには送られず、使っている端末のブラウザの中だけに保存されます。
そのため、別の端末とは同期しません。ブラウザの履歴やサイトデータを消すと、内容も消えます。

## アプリを更新したとき

`index.html` を書き換えてアップロードしたら、`sw.js` の1行目あたりにある
`var VERSION = "v1";` の数字を `"v2"` のように増やしてください。
次に開いたときに新しい内容が読み込まれます。
